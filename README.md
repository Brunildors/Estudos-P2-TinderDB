# Estudos do TinderDB

Material de estudo para a defesa do Desafio P2 de Banco de Dados (SQL Server): um banco relacional inspirado no Tinder. Projeto acadêmico, sem vínculo com o Tinder. Todos os dados do banco de exemplo são fictícios.

**Site:** https://brunildors.github.io/Estudos-P2-TinderDB/

O site reúne o resumo da matéria, o roteiro de estudos, o resumo da defesa e um questionário de 30 perguntas com correção na hora.
